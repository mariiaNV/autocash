# AVTOCASH — сайт (Next.js 15)

Викуп авто, автоломбард, гроші під заставу авто та власна автомийка в Одесі.
**Слоган:** «Ваше авто — ваші гроші. Швидко та прозоро.»

```bash
npm install
npm run dev        # http://localhost:3000  (UA)  ·  http://localhost:3000/ru  (RU)
npm run build && npm start
```

Стек: Next.js 15 (App Router, SSG), React 19, Tailwind CSS (токени), GSAP + ScrollTrigger, Lenis, Lucide.

## Публікація на GitHub Pages

Проєкт налаштований на статичний експорт і автоматичну публікацію через `.github/workflows/deploy-pages.yml`.

1. Створіть GitHub-репозиторій і запуште код у гілку `main`.
2. У репозиторії відкрийте **Settings → Pages**, у полі **Source** виберіть **GitHub Actions**.
3. Після завершення workflow сайт буде доступний за адресою `https://<username>.github.io/<repository>/`.

Workflow автоматично підставляє назву репозиторію як `basePath`, тому локальні зображення з `public/images/`, CSS та JavaScript завантажуються і на project site. Для власного домену замініть `NEXT_PUBLIC_BASE_PATH` у workflow на порожнє значення та оновіть `site.url` у `lib/site.ts`.

## Мови

- Українська — основна, відкривається на `/`. Російська — на `/ru`. Перемикач UA / RU є в шапці та в мобільному меню.
- Усі тексти зібрані в `lib/i18n.ts`: меню, кнопки, форма, помилки, футер, SEO та alt-тексти зображень.
- Маршрути: `app/[locale]`, rewrite `/` → `/uk`, redirect `/uk` → `/`. Є `hreflang`, `canonical`, `og:locale` і `sitemap` з альтернативними мовними версіями.

## ⚠️ Що заповнити перед запуском реклами (`lib/site.ts`)

| Поле | Статус |
|---|---|
| `phone` | **Заглушка** `+38 (0XX) XXX-XX-XX`. Вкажіть реальний номер: він використовується в усіх кнопках «Зателефонувати». |
| `url` | Бойовий домен (canonical, OG, sitemap) |
| `messengers` | Telegram / Viber / WhatsApp. Поки поле порожнє, кнопка не показується. |
| `NEXT_PUBLIC_LEAD_ENDPOINT` | Адреса CRM чи вебхука для заявок. Без неї форма працює в демо-режимі (перевіряє поля й показує екран успіху, але нікуди не відправляє). |
| Показники «10+ / 30 хв / 500+ / 24/7» | **Демонстраційні** (`statsAreDemo: true`). Замініть на погоджені з клієнтом дані. |

## Прайс автомийки

Перенесено з актуального фото прайсу клієнта в `lib/site.ts → prices`. Колонки A–D — класи авто: легкове, кросовер, мінівен, мікроавтобус. На телефоні є вкладки категорій і перемикач класу, тому видно одну колонку цін.

## Архітектура

- Уся розмітка серверна, сторінки генеруються статично. Без JS сайт повністю читається, а посилання й телефони працюють.
- `lib/enhance.ts` — уся інтерактивність в одному модулі: меню, форма з валідацією та станами (завантаження / успіх / помилка), вкладки прайсу, мобільна панель, анімації GSAP і Lenis. Підключається через `components/Enhance.tsx`.
- Бігуча стрічка зроблена на чистому CSS, без розривів. На наведенні зупиняється, при `prefers-reduced-motion` вимкнена.
- `prefers-reduced-motion`: вимикаються Lenis, GSAP, бігуча стрічка та відблиск на авто.

## Статичне превʼю

`preview-static/index.html` — та сама сторінка без збірки. Відкрийте файл у браузері; мова перемикається через `#ru` / `#uk`. Фото з Unsplash вантажаться з інтернету.
